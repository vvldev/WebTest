# Блог на чистом PHP

Блог с категориями и статьями: главная с последними статьями каждой категории, страница категории
с сортировкой и пагинацией, страница статьи со счётчиком просмотров и похожими статьями.

**Стек:** PHP 8.3 (код совместим с 8.1), MySQL 8 (PDO), Smarty 5, SCSS (dart-sass), Docker. Без фреймворков.

## Запуск

Нужны Docker и Docker Compose.

```bash
cp .env.example .env
make up        # сборка и запуск контейнеров
make install   # зависимости composer
make seed      # тестовые категории, статьи и картинки
```

Сайт: http://localhost:8080

Если порт 8080 занят, поменяйте `APP_PORT` в `.env` и выполните `make up`.

## Команды

| Команда | Что делает |
|---|---|
| `make up` | собирает образы и запускает контейнеры |
| `make down` | останавливает контейнеры |
| `make install` | устанавливает зависимости composer |
| `make seed` | пересоздаёт категории, статьи и картинки (старые удаляются) |
| `make db-reset` | удаляет базу и создаёт её заново по `schema.sql` |
| `make sh` | shell в контейнере PHP |
| `make logs` | логи всех контейнеров |

## Что где лежит

| Папка | Назначение |
|---|---|
| `public/` | корень сайта: точка входа `index.php`, собранный CSS, картинки статей |
| `src/Controller` | контроллеры страниц: главная, категория, статья |
| `src/Service` | вычисления над данными: пагинация, учёт просмотров |
| `src/Repository` | весь SQL: интерфейсы репозиториев, реализации на PDO, маппинг строк в DTO |
| `src/Dto` | объекты для передачи данных между слоями |
| `src/Enum` | варианты сортировки (whitelist для `ORDER BY`) |
| `src/Http` | запрос, ответ, роутер, обработка ошибок |
| `src/View` | подключение Smarty через адаптер |
| `src/Database` | фабрика PDO |
| `src/Seed` | сидер на Faker и генератор картинок на GD |
| `templates/` | шаблоны Smarty: `layout.tpl`, страницы, общие части |
| `scss/` | стили: переменные, база, раскладка, компоненты (BEM) |
| `config/` | настройки приложения и список маршрутов |
| `docker/` | Dockerfile PHP, конфиг nginx, схема БД |
| `bin/` | консольный скрипт сидинга |
